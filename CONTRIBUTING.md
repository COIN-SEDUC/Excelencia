# CONTRIBUTING.md

Este repositório segue o padrão oficial do time COIN/SEDUC definido no repositório `modelo_repositorio`.

## Regras obrigatórias

* Trabalhar sempre em branch pessoal `dev_<nome>`
* Nunca desenvolver diretamente na branch `main`
* Atualizar o `README.md` antes do merge com a data e a descrição da alteração
* Revisar o diff antes de commit e push
* Validar job, pipeline ou relatório após publicar na `main`
* Manter a estrutura padrão do repositório com `DDL/`, `DML/`, `PBIP/`, `README.md` e `CONTRIBUTING.md`
